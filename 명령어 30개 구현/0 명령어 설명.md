# Ubuntu/Linux Command Summary

1. **echo** : 인자로 전달된 문자열을 그대로 출력한다.
2. **clear** : 터미널 화면을 깨끗하게 지운다.
3. **whoami** : 현재 로그인한 사용자 이름을 출력한다.
4. **hostname** : 시스템의 호스트 이름을 출력한다.
5. **sleep** : 지정한 시간(초) 동안 실행을 일시 정지한다.
6. **rmdir** : 비어 있는 디렉터리를 삭제한다.
7. **ln** : 기존 파일에 대한 하드 링크 또는 심볼릭 링크를 생성한다.
8. **dirname** : 전체 경로에서 디렉터리 경로만 추출한다.
9. **cat** : 파일 내용을 출력하거나 여러 파일을 연결하여 출력한다.
10. **touch** : 빈 파일을 생성하거나 파일의 수정 시간을 갱신한다.
11. **mv** : 파일 또는 디렉터리를 이동하거나 이름을 변경한다.
12. **head** : 파일의 처음 부분을 지정한 만큼 출력한다.
13. **tail** : 파일의 마지막 부분을 지정한 만큼 출력한다.
14. **uptime** : 시스템이 부팅된 이후 경과한 시간을 출력한다.
15. **wc** : 파일의 줄 수, 단어 수, 문자 수 등을 출력한다.
16. **rev** : 입력된 문자열을 역순으로 출력한다.
17. **uname** : 현재 사용 중인 커널 및 시스템 정보를 출력한다.
18. **cal** : 달력을 출력한다. (구현에는 월만 표시되도록 함.)
19. **arch** : 시스템 아키텍처 정보를 출력한다.
20. **cp** : 파일 또는 디렉터리를 복사한다.
21. **find** : 지정한 경로에서 조건에 맞는 파일이나 디렉터리를 검색한다.
22. **head -n** : 파일의 처음 n줄을 출력한다.
23. **tail -n** : 파일의 마지막 n줄을 출력한다.
24. **env** : 현재 환경 변수 목록을 출력한다.
25. **stat** : 파일 또는 디렉터리의 상세 정보를 출력한다.
26. **basename** : 전체 경로에서 파일 이름만 추출한다.
27. **kill** : 특정 프로세스에 시그널을 보내 종료하거나 제어한다.
28. **nice** : 프로세스를 지정한 우선순위로 실행한다.
29. **renice** : 실행 중인 프로세스의 우선순위를 변경한다.
30. **bg** : 중지된 작업을 백그라운드에서 계속 실행한다.
